## 🚀 Projets Phares

### 1. 🛒 E-Commerce & Prédiction d'Achat (GA4 + XGBoost)
* **Le Problème :** Analyser de larges volumes de données comportementales pour identifier les signaux d'achat des utilisateurs.
* **La Solution :** Conception d'un pipeline complet d'ingénierie des caractéristiques (*feature engineering*) à partir de données Google Analytics 4 (GA4) extraites de Google Cloud BigQuery, couplé à un modèle de classification **XGBoost** optimisé.
* **Le Résultat :** Une application interactive fluide déployée sur **Streamlit** permettant de prédire en temps réel la probabilité qu'un utilisateur concrétise son achat.
* **🔗 [Voir le dépôt du projet](https://github.com/lintello-10/bq_ecommerce_project)** 

### 2. 🚢 Application Prédictive de Survie - Titanic
* **Le Problème :** Explorer un dataset classique de classification pour prédire le destin des passagers selon différents facteurs socio-démographiques.
* **La Solution :** Réalisation d'une analyse exploratoire approfondie (EDA), nettoyage rigoureux des données, traitement des valeurs manquantes et entraînement de modèles prédictifs performants via **Scikit-Learn**.
* **Le Résultat :** Un flux de travail de bout en bout propre, documenté et versionné, démontrant la maîtrise des fondamentaux du Machine Learning.
* **🔗 [Voir le dépôt Titanic](https://github.com/lintello-10/Titanic-Data-cleaning-Features-Engineering)**
