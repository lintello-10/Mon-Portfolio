API MLOps E-Commerce — Prédiction d'achat en temps réel

● Live

FastAPI · XGBoost · Docker · Render

Problème : transformer un modèle de Machine Learning brut en un service web sécurisé, accessible en temps réel et prêt pour la production.

Solution : API REST asynchrone avec validation stricte des données (Pydantic, contraintes ge=0), gestion d'exceptions personnalisée et endpoint de monitoring /health ; conteneurisation Docker et déploiement cloud sur Render.

Résultat : service performant, documentation interactive Swagger UI et reproductibilité totale par conteneur.

Analyse & prédiction d'achat — GA4 + BigQuery

● App live

BigQuery SQL · XGBoost · Streamlit

Problème : extraire et analyser un large volume de données comportementales (Google Analytics 4) pour identifier les signaux d'achat des utilisateurs.

Solution : requêtage SQL avancé de structures imbriquées sur Google Cloud BigQuery, feature engineering sur plus de 79 000 lignes, entraînement d'un classificateur XGBoost.
